# Pokédex Kanto

Mini página con 5 Pokémon de Kanto + sección de Regiones. Hecha con HTML semántico y CSS aparte, sin JavaScript.

## Qué tiene

- 5 tarjetas: Pikachu, Charmander, Squirtle, Bulbasaur y Mewtwo
- Sección Regiones: Kanto, Johto y Hoenn con imagen
- Nav píldora con logo + Inicio, Pokédex, Tipos, Regiones
- Responsive: 1 columna en celular, 2 en tablet, 3 en PC

## Estructura

```
pokemon-pokedex/
  index.html
  assets/css/styles.css
  img/ 
```

## Cómo verla

1. Abre la carpeta `pokemon-pokedex`
2. Doble click en `index.html`
3. Se abre en tu navegador, no necesita servidor

## Tecnologías

- HTML5 
- CSS3 
- Imágenes locales PNG
